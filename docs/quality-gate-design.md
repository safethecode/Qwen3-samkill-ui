# Local quality gate

The user wants unattended generation, visual inspection and repair against samkill-ui references. Automated functional success must not be presented as design approval. Local inference is required; no code comments or personal paths belong in published source. Existing authorization includes granular commits and push without further questions.

Add a quality runner around the existing fixture workflow. A required QUALITY.json declares desktop/mobile reference images and scoped reference observations. Reference files are resolved relative to that manifest and hashed. Missing references, unavailable vision, malformed/truncated review, stale evidence and timeouts fail closed. Existing iterate remains explicitly a functional-only command; quality is the documented completion command.

Use a fresh local vision request per viewport. Fixed criteria cover composition, hierarchy, spacing, typography, content previews and action priority. Every criterion needs an observed comparison, confidence and score; concrete defects need location and a repair condition. All criteria must score at least 4/5 with confidence at least 0.8, and no issues may remain. A separate adversarial confirmation must independently pass both viewports on identical source/images before COMPLETE. This is model judgment, not a guarantee of aesthetic equivalence.

Repairs consume one concrete defect and current source. After two unsuccessful attempts, regenerate affected complete files through the existing validated replacement mode. Do not regenerate the entire application or weaken criteria. Preserve all passing functional checks and all prior visual criterion scores; reject regressions and ineffective edits. Restore source after failed candidates or infrastructure errors. Stop at a finite budget with INCOMPLETE. Persist source/image/reference hashes, decisions, raw review content without reasoning, rejected candidates and a machine summary.

Use dependency-injected orchestration for tests of rollback, confirmation failure, escalation, stale source and exhausted budgets. Test reviewer validation and local request composition separately. Run real browser tests and a local vision trial against existing saved artifacts and actual Round 09 references. Publish outcomes including failures; calibration on a few fixtures does not establish general reliability.
