# 모바일 적용 기준

모바일 화면을 만들 때만 읽는다. 모바일 레퍼런스를 데스크톱에 단순 확대하지 않는다.

- 실제 과제에 맞는 읽기/탭 순서를 보존한다. CTA가 화면 아래에 보인다는 사실과 fixed 구현은 별개다.
- 목표 좁은 폭, 긴 한국어, 큰 글자 설정, 키보드가 열린 입력 상태에서 잘림과 행동 접근을 확인한다.
- bottom sheet는 내용 높이·safe area·스크롤 영역·닫기 동작을 명시한다. 정지 화면으로 drag-to-dismiss나 배경 탭 닫기를 확인했다고 하지 않는다.
- 손가락으로 누를 수 있는 영역과 아이콘 자체 크기를 구분한다. hover에 의존하지 않고 focus와 접근 가능한 이름을 유지한다.
- 작은 화면에서 핵심 정보를 감추기 전에 사용자가 비교해야 하는 필드를 정한다. 가격·옵션·오류를 생략해 카드 높이만 줄이지 않는다.
- loading/empty/error에서 레이아웃이 급변하거나 CTA가 의도치 않게 이동하는지 확인한다.
- 모바일 원본에 없는 태블릿/데스크톱 동작은 새 설계 결정으로 기록한다.

- [UI 구성 기준](ui-composition.md)에 따라 읽는 글자는 기본14 CSS px 이상, 본문/입력은16px부터 검토한다. 공간이 좁은 보조정보의12px 예외는 해당 기준의 조건과 실제 검증을 따른다. 모바일 화면 전체를 축소하지 않는다.
- 기본·빈 목록·소수 항목에서 불필요한 스크롤이 없는지 확인한다. 긴 내용과 키보드 상태에서 필요한 스크롤은 막지 않는다.
- 목록과 채팅을 함께 요청받으면 두 과제의 공간 경쟁부터 검토한다. 탭/뷰 분리 시 입력 초안과 목록 상태, 탭 복귀 위치를 보존하고 키보드·결과 확인까지 실행한다.

## 탭을 큰 버튼 두 개처럼 만들지 않기

아이콘/작은 컨트롤은 [아이콘 영역 계약](icon-controls.md)으로 실제 클릭 영역의 확장·충돌·가림과 터치 hover 잔류를 확인한다. 크기 선언과 실제 누를 수 있는 범위를 구별한다.

탭은 목적지 전환이고 CTA는 실행이다(RUI-19). 별도 화면으로 나누었다는 사실만으로 모바일 구성이 완성되지 않는다. 모바일 레퍼런스에서 위치·선택 표시·아이콘/라벨 관계·바 높이를 실제로 확인한다.

주요 목적지를 오가면 하단 내비게이션, 같은 작업의 하위 보기라면 상단의 간결한 탭/선택 그룹을 검토한다. 항목 수를 채우기 위해 가짜 목적지를 추가하지 않는다. 두 탭이라고 항상 하단 막대로 만들거나 데스크톱 세그먼트 버튼을 화면 너비로 늘리지 않는다.

하단을 선택했다면 같은 중심선에 놓인 아이콘/라벨과 충분한 터치 영역을 구성한다. 세로 아이콘+라벨 또는 원본에 근거한 간결한 가로 표현을 선택한다. 활성 탭 전체 셀을 큰 회색 사각형으로 채우지 않고 글자/아이콘 대비·굵기·제한된 표시 영역 등으로 상태를 구분한다. 탭 아래 긴 기준선과 선택 밑줄/이동 바도 사용자의 바 금지 범위에 포함한다. 탭 관례라는 이유로 추가하지 않는다. 선택 상태는 글자 굵기와 적절한 표면 등 선 이외의 표현을 조합하고 색상만으로 구분하지 않는다. 사용자에게 읽히는 라벨은 14px 하한을 유지하고 대상을 모호하게 만드는 아이콘 단독화로 줄이지 않는다.

바의 내용 높이와 safe-area-inset-bottom을 분리해 중복 여백을 막는다. min-height를 채우려고 버튼을 세로 stretch해 거대한 채움 영역을 만들지 않는다. 입력창·콘텐츠 하단 padding과도 높이를 한 번만 예약한다. 실제 viewport에서 막대가 소비하는 높이, 아이콘/라벨의 균형, 선택 면적, 탭 전환·복귀·키보드·포커스를 원본과 비교한다. px 수치만 맞추거나 role=tab을 붙인 것만으로 ‘모바일 앱스럽다’고 통과하지 않는다.

## 좁은 가로 선택 목록

많은 시간·옵션을 한 줄로 비교하도록 설계하면 내용에 맞는 짧은 선택 버튼과 가로 넘김을 함께 검토한다. 선택영역을 화면폭에 맞춰 과도하게 늘리거나 전체 페이지의 가로 넘침으로 대체하지 않는다. 스크롤바 숨김을 요구받으면 해당 영역에 한정해 적용하고, 다음 항목의 부분 노출 등 실제 넘김 가능성이 드러나는 단서를 남긴다. 항목이 모두 보이면 거짓 넘김 단서를 만들지 않는다.

터치/트랙패드와 키보드 포커스로 마지막 항목까지 도달하는지, 선택값과 스크롤 위치가 복귀 시 어떻게 유지되는지 확인한다. 확대에서는 숫자/레이블을 자르지 않고 버튼이 내용만큼 늘어나게 한다. 작은 선택 버튼도 기본 글자14px와 터치영역 기준을 유지하며, 보조정보12px 예외를 행동 라벨에 확장하지 않는다.
