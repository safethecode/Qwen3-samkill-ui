# 근거 없는 디자인을 막는 판단표

orc의 reference-first, WHAT IS ABSENT, 비교 검토와 컴포넌트별 DO NOT을 발전시킨 규칙이다. 특정 미학을 AI의 증거로 판별하는 표가 아니다. 과제·사용자 지시·기존 브랜드·실제 관찰을 기준으로 판단한다.

## 원본 실패 기준과의 관계

[실패 목록](../../reference-review/references/failure-catalog.json)의 활성 규칙을 먼저 계약에 포함한다. 아래 표의 유지 근거는 자동 허용 조건이 아니다. 원본 금지 기준과 충돌하면 관련 ID, 해당 요소·상태, 사용자 요구나 관찰 근거, 대안과 검증 결과를 [게이트](../../reference-review/references/design-gate.md)의 예외 절차로 남긴다. 이전 실패 기록도 함께 검사하며 ‘결함이 아닐 수도 있다’는 말로 해제하지 않는다.

## 기본 원칙

새로운 시각 요소에는 정보 구분, 행동 강조, 피드백, 콘텐츠 표현, 브랜드 중 구체적 역할이 있어야 한다. 역할을 설명할 수 없는 효과는 추가하지 않는다. 이미 존재하는 요소도 아래 조건에 해당하면 검토한다. 역할을 설명하기 위해 사후에 근거를 지어내지 않는다.

| 조건/점검 대상 | 이번 화면에서 피할 것 | 적용할 대안 | 예외 검토에 필요한 근거 |
|---|---|---|---|
| 주문 비교·필터·일괄 작업이 핵심 | 항목을 대형 카드와 대시보드 KPI로 대체 | 정렬된 목록/테이블, 필요한 필터·선택 행동 | 이미지 탐색이 핵심인 상품 목록은 카드가 적합 |
| 콘텐츠보다 장식이 먼저 보임 | 근거 없는 그라디언트 hero, glow, blob, glass | 위계·여백·단색 표면으로 구분 | 명시된 브랜드 효과나 관찰된 콘텐츠 표현은 유지 |
| 모든 영역이 같은 큰 둥근 박스 | 카드 안에 카드, 과도한 padding, pill 남발 | 의미 단위만 묶고 간격·정렬·필요한 표면 차이 사용 | 바텀시트·터치 UI·브랜드 토큰은 별도 근거 |
| 반복 항목마다 다른 색 | 무지개 배지·아바타·아이콘으로 서열 왜곡 | 중립 기본 + 의미가 있는 색/텍스트 | 사용자 지정 식별 색이나 실제 범주 범례가 있으면 유지 |
| 모든 항목이 호버 때 움직임 | scale/glow/튀어오름을 일괄 적용 | 명확한 hover/focus/pressed 피드백 | 제품이 요구하는 직접 조작·공간 이동은 목적대로 구현 |
| 도구 화면인데 첫 화면이 소개 문구 | 거대한 제목, 모호한 슬로건, 환영 hero | 과제 제목과 실제 데이터/행동을 먼저 배치 | 마케팅 페이지의 메시지 위계는 별도로 판단 |
| 독창성을 만들려고 모양을 바꿈 | 억지 비대칭, 카드 크기 랜덤화, 영역별 다른 스타일 | 콘텐츠 중요도에 맞춘 리듬과 일관된 규칙 | 편집 우선순위·이미지 비율 차이에 근거한 변형 |
| 컨테이너마다 scrollbar | 짧은 목록에 고정 높이와 중첩 스크롤 | 내용에 따른 높이·단일 흐름 | 표의 가로 넘침, 로그, 긴 모달 등 기능상 필요하면 허용·검증 |
| 같은 행동이 경쟁적으로 반복 | 동일 위계의 중복 CTA | 맥락마다 주요 행동을 명확히 구분 | 긴 페이지의 CTA 반복 등 위치별 사용자 필요가 있으면 유지 |
| 간결함을 위해 행동을 숨김 | hover-only 필수 행동, 설명 없는 아이콘 | 키보드·터치에서도 찾고 실행할 수 있게 제공 | 보조 행동도 focus/touch 접근 방법이 확인되어야 함 |
| 데이터와 문구가 데모 티를 냄 | 무관한 통계·가짜 추천사·의미 없는 영어·상투적 오류 | 제품의 실제 정보, 상태와 다음 행동 | 데모 데이터는 명시하고 실제 길이/범위를 반영 |
| 기본 컴포넌트를 붙였지만 레퍼런스와 다름 | 라이브러리 기본값을 완성 디자인으로 취급 | 기존 접근성 동작을 보존하며 토큰/간격/밀도 조정 | 기존 시스템과 이미 맞는 기본값은 변경 불필요 |

## Avoid 기록법

`A1 — 주문 카드의 hover scale을 추가하지 않는다. 근거: 주문 비교가 핵심이고 선택한 정지 화면에는 움직임 근거가 없다. 대안: 행 배경과 명확한 focus 표시. 미확인: 원본 hover 동작.`

이는 “그 제품은 hover scale을 절대 쓰지 않는다”라는 주장이 아니다. 관찰하지 못한 동작은 unknown이고, 이번 구현의 생략은 과제에 따른 결정이다.

## 판단이 흔들릴 때

| 유혹 | 확인할 사실/행동 |
|---|---|
| “심심하니 KPI 네 개를 넣자” | 사용자에게 필요한 의사결정 지표인지 확인. 없으면 추가하지 않는다. |
| “보라색이면 AI 같다” | 사용자가 지정한 브랜드인지 확인. 맞으면 충돌하는 원본 규칙의 예외 범위와 근거를 기록하고 실제 구조 문제도 검사한다. |
| “레퍼런스 세 개를 섞으면 안전하다” | 주 화면의 위계를 정한 뒤 보조 패턴의 역할만 차용한다. |
| “카드를 다 다르게 만들면 개성 있다” | 콘텐츠 역할이 같은지 확인. 같다면 같은 표현으로 비교를 돕는다. |
| “스크린샷에 없어도 당연히 fixed다” | 관찰된 사실과 새 구현 결정을 분리한다. |

전체를 회색 미니멀 UI로 통일하는 것도 근거 없는 기본값이다. 제품의 개성은 과제, 콘텐츠, 브랜드, 타이포그래피, 이미지 사용에서 확보한다.
