# 데이터 작업 화면 적용 기준

조회·비교·정렬·선택·일괄 작업이 핵심인 화면에서만 읽는다. 한국어 화면이라는 이유로 밀도를 일괄 높이지 않는다.

- 레퍼런스의 내용 유형을 확인한다. 관리 도구와 마케팅 랜딩 페이지를 같은 밀도로 만들지 않는다.
- 테이블/목록/카드는 항목 수만으로 결정하지 않는다. 비교할 열, 텍스트·이미지 중요도, 실행할 행동에 맞춘다.
- 불필요한 hero/KPI/차트를 추가하지 않는다. 지표가 있다면 값·기간·단위·사용 목적을 정의한다.
- 금액/수량 정렬, 날짜 형식, 헤더-셀 정렬, 긴 이름/빈 셀/많은 행을 실제 데이터 범위로 확인한다.
- 선택 범위가 현재 페이지인지 전체 결과인지 표시한다. 부분 선택, 필터 변경, 일괄 작업 중/부분 실패 뒤의 선택 보존 정책을 정한다.
- 상태는 텍스트로 구별하고 색상은 의미를 보조한다. 다채로운 브랜드를 강제로 회색으로 만들지 않는다.
- 스크롤/고정 열/페이지 분할은 필요한 작업과 데이터량에 근거한다. 강제 높이로 위젯의 빈 공간을 숨기지 않는다.
- 같은 너비뿐 아니라 높이도 맞춰 밀도를 비교한다. 원본 높이가 없으면 정확한 visible row 수가 아닌 추정 목표로 기록한다.
