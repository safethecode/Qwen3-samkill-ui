# 장식·문구 탐지 결과를 판독하기

AI처럼 보이는 UI 개선, 장식/문구 정리, 외부 탐지 결과 리뷰에 사용한다. 탐지기는 작성 주체나 제품 품질을 판별하지 않는다. 기존 [실패 목록](failure-catalog.json)의 활성 규칙과 사용자 제외 조건은 그대로 검사한다. 여기의 반례로 기존 금지·실패를 일괄 해제하지 않는다.

## 위치에서 근거로

`검색 신호 | 파일/영역 | 실제 역할 | 원본·요구 근거 | 관련 규칙/Q-ID | 유지/수정/미확인 | 재검증`으로 판독한다. 검색/스캐너 일치는 후보이며 실제 코드·화면에서 확인한 문제만 확정한다. 도구가 잡지 못한 이미지·동적 CSS·한국어 문구도 관련 검사에서 빠뜨리지 않는다.

| 신호 | 확인할 문제 | 보존할 반례 |
|---|---|---|
| 헤더마다 kicker·배지·번호 | 제목 반복, 근거 없는 인기/실시간, 순서 없는 기능의 장식 번호 | 실제 카테고리·날짜·재고·설치 순서 |
| 아이콘 타일·상태 점·강조 단어 | 장식이 실제 판단/행동보다 강함, 데이터 없는 live 점 | 의미 있는 기능 아이콘·확인된 상태·검색 일치 강조 |
| 카드 안 카드·같은 gap 반복 | 독립 객체가 아닌데 표면/패딩 중첩, 내부와 외부 간격 혼동 | 독립 미리보기·임베드, 의도된 균일 달력/사진 목록 |
| 통계와 성과 문구 | 출처 없는 수치/보장, 조건 삭제로 범위 확대 | 출처·기간·모수·비교 대상이 있는 실제 수치 |
| 검정+모노, 크림+세리프, 익숙한 sans | 제품 과제·콘텐츠와 무관하게 유행을 일괄 적용 | 실제 코드 도구, 편집 콘텐츠, 기존 브랜드·한글 지원 근거 |
| 그라디언트·glow·hover 확대 | 의미 없는 효과와 시선 경쟁, 상태 불명확, 조작 방해 | 실제 데이터 표현·원본 특징·사용자 요구를 관련 규칙과 대조한 적용 |

구분선으로 카드를 대신하거나 모든 화면을 회색·작은 반경·같은 폰트로 바꾸지 않는다. RUI-14의 영역 구분 바/탭 선 금지, RUI-09의 실제 표시 크기, RUI-12의 Lucide 기준을 유지한다. 사진·제품 표현의 개성이 사라지면 Q-ID의 긍정 비교도 다시 판독한다.

## 문구와 스캐너의 한계

과장·기계적 삼단 문장·불필요한 강조를 발견하면 [한국어 기준](../../ux-copy/references/korean-writing.md)으로 실제 내용과 문장 구조를 고친다. 단어 하나를 금지어로 치환하거나 실험 수치를 새로 만들어 구체성을 채우지 않는다. 확인된 수치·부정·비용·조건·가능성을 원문과 대조한다.

[yetone scanner](https://github.com/yetone/kill-ai-slop/blob/96d1ca568a1db7e1ef9a381644c744440f816ee4/skill/scripts/scan.mjs)를 별도로 사용할 때는 revision, 대상 경로, 제외 경로, only/skip ID, 추가 규칙, ignore 억제를 기록한다. 신호 수의 전후 비교는 같은 설정/범위에서만 가능하며 0건도 시각 PASS가 아니다. 언어별 규칙이 없으면 한국어 탐지 완료라고 하지 않는다. 억제 주석은 프로젝트 예외 선언·근거·재검증을 대신하지 않는다.

scanner는 여기 번들로 제공하지 않는다. 필요하면 검토한 고정 revision과 라이선스를 확인해 사용하거나 기존 `rg`로 관련 후보를 찾는다. dmmulroy/anti-slop의 TS/JS 타입·코드 검사와 별개이므로 서로의 통과를 대신하지 않는다.

수정 요청이 있으면 판독한 문제를 승인된 범위에서 수정하고 실제 전후 비교를 수행한다. 리뷰만 요청하면 근거·수정안을 전달한다. 매 후보마다 재승인을 요구하지 않는다.

근거: [Yetone taxonomy/detection/fixes](https://github.com/yetone/kill-ai-slop/tree/96d1ca568a1db7e1ef9a381644c744440f816ee4/skill/references)를 samkill의 실패 보존·긍정 비교·한국어 계약에 맞춰 적용했다. 원본의 단일 색/반경·hairline·생성 기능 아이콘 처방은 이식하지 않았다.
