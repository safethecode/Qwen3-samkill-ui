# Samkill UI

`$samkill-ui`를 단일 진입점으로 사용한다. 요청에 해당하는 아래 스킬을 직접 읽고 실행한다. 사용자에게 스킬을 다시 호출하라고 넘기거나 모든 스킬을 한꺼번에 읽지 않는다. 세부 기준은 각 스킬을 관리 원본으로 유지한다.

## 시작

작업 대상 프로젝트와 요청 범위부터 확인한다. 대상의 `AGENTS.md`, 루트 `DESIGN.md`, 관련 맥락·계약·실패 기록이 있으면 읽는다. 이 스킬이 설치된 저장소를 대상 제품으로 착각하지 않는다. 이미 제공된 요구와 충분한 레퍼런스·분석은 재사용한다.

필요한 스킬과 이유를 짧게 알리고 작업을 이어간다. 아래 표는 선택 기준이며 전부 거치는 체크리스트가 아니다. 구현 중 문구나 가입 흐름이 생기면 그때 해당 스킬을 추가한다.

## 요청별 연결

| 요청 또는 현재 단계 | 읽고 적용할 스킬 | 범위 |
|---|---|---|
| 레퍼런스 검색·앱 비교·상세 조사 | [uibowl-research](../uibowl-research/guide.md) | 실제 이미지와 출처를 확인한다. 검색만 요청하면 결과 전달에서 끝낸다. |
| 설계·구현용 원본 확보, 요소 분석·재현 실험 | [reference-decompose](../reference-decompose/guide.md) | 각색·구현 전에 요소·관계·조립 계약을 만든다. 유효한 기존 분석은 재사용한다. |
| UI 설계·구현·리디자인·토큰 수정 | [reference-to-ui](../reference-to-ui/guide.md) | 사용자 과제와 레퍼런스 장점을 연결해 요청한 화면을 만든다. 필요한 조사·분해와 최종 리뷰까지 이어간다. |
| 대상 DESIGN.md 작성·갱신, 구현 전 문서 누락 | [design-md](../design-md/guide.md) | 실제 제품 자료로 기준을 정리한다. 읽기 전용이면 누락·변경안만 보고한다. |
| 한국어 UI 문구 작성·교정 | [ux-copy](../ux-copy/guide.md) | 행동·조건·비용·선택권을 보존한다. 문구만 요청하면 화면 재설계를 추가하지 않는다. |
| 가입·첫 사용·동의·실패 복구 흐름 | [onboarding-flow](../onboarding-flow/guide.md) | 상태·전이·뒤로 가기·재진입을 연결한다. 화면 구현 여부는 사용자 범위를 따른다. |
| 기존 화면 리뷰, 구현 후 검증 | [reference-review](../reference-review/guide.md) | 실제 화면·행동·토큰과 실패 기록을 대조한다. 리뷰만 요청하면 수정하지 않는다. |

## 구현 요청의 진행과 종료

`reference-to-ui`를 중심으로 필요한 분기를 연결해 실제 작업을 완료한다. 레퍼런스가 충분하면 재검색하지 않는다. 새 원본은 `reference-decompose`로 분석한 뒤 적용하며, 핵심 화면을 원본과 먼저 비교한 후 의존 화면으로 확장한다. 한국어 문구는 `ux-copy`, 가입·복구는 `onboarding-flow`를 함께 적용한다.

각 스킬이 요구하는 구성·토큰·코드·시각·행동 검사를 생략하지 않는다. `reference-review`의 디자인 게이트와 실패 목록을 적용하고, 권한 내 중요한 차이를 수정·재검증한다. 빌드 성공을 시각 검증으로 바꾸거나 FAIL/UNVERIFIED를 완료로 표시하지 않는다.

명세만 요청하면 `spec-only`, 읽기 전용이면 분석과 수정안으로 종료한다. 형식 미지정 UI 디자인은 수정·렌더 가능한 화면으로 제공한다. 문구·검색·리뷰 전용 요청에 전체 구현 절차를 강제하지 않는다. 호출 자체로 커밋·푸시·배포·외부 전송 권한을 만들지 않는다.

읽기 전용에서는 리뷰 문서·게이트 보고서·ledger 누적도 대상 파일에 쓰지 않고 결과를 채팅으로 전달한다. 기록을 생성하지 못한 검사와 실제 수행한 판독 범위를 구별한다.

## 연결과 도구가 없을 때

표의 링크는 이 파일의 실제 위치를 기준으로 한 형제 스킬 경로다. 링크를 열 수 없으면 세션의 설치 스킬 목록에서 같은 이름을 찾아 읽는다. 둘 다 없으면 누락된 스킬을 명시하고 접근 가능한 기준과 사용자 자료로 독립 작업을 이어간다. 읽지 못한 기준을 적용했다고 하거나 검증 불가능한 항목을 통과시키지 않는다.

UIbowl 등 도구의 연결·인증 실패는 검색 성공과 구별한다. 제공된 이미지·기존 계약으로 가능한 작업은 계속하고 직접 확인하지 못한 부분을 표시한다. 자동 설치나 인증 변경을 전제로 하지 않는다.

결과는 실제 산출물, 주요 결정, 수행한 검증, 남은 미확인 사항으로 전달한다. 선택한 스킬 목록만 출력하고 끝내지 않는다.
