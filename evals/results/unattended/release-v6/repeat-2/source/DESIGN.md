# 이력서 관리 화면 평가 계약
참고 기준: samkill-ui Round9의 문서 목록과 편집 흐름. 전체 서비스 복제가 아니라 핵심 목록/작성/검색/복제/보관의 완결성 평가다.
주 과제: 지원처별 이력서를 만들고 보관하며 다음 방문에도 내용을 유지한다.
화면: 중립 #f5f6f8 바탕, 흰 문서 미리보기, 본문 #20252d, 보조 #606873, 주요 행동 #1765e8. 14px 이상, 굵기500 이상. 제목24px, 본문16px. 최대1160px, 데스크톱 여백32px/모바일20px. 역할 토큰 사용. 장식 구분선, 탭 밑줄, 임의 로고/아이콘, KPI, 큰 홍보 히어로 금지. 모션 줄이기/포커스 유지.
목록: 제목 '내 이력서', 설명 '이 브라우저에 저장됩니다', 주 행동 '새 이력서', 제목/직무 검색 input label '이력서 검색', 필터 '전체'/'보관함'. 3개 예시 문서(예시 표시), 흰 종이 미리보기, 제목/직무/수정일/편집·복제·보관 행동. 종이 미리보기는 문서 내용의 일부를 보여준다.
작성 폼: 제목, 이름, 직무, 이메일, 소개에 각각 눈에 보이는 label을 표시한다. label 표시 의무와 입력값 필수 여부는 다르다. 소개는 선택 입력이며 비워도 저장할 수 있다. 저장/취소. 빈 제목 저장 금지, 한국어 오류 표시. 저장하면 목록 반영.
복제는 원본 내용으로 새 독립 문서를 만든다. 보관하면 전체에서 빠지고 보관함에 나타나며 복원 가능. 새로고침 후 저장 유지. 빈 검색 결과는 명확한 안내. 실제 서버·AI·제출 기능을 주장하지 않는다.
기술: 외부 의존성 없는 index.html/styles.css/app.js 3개 파일. JS 문법검사 가능. 코드를 답변으로만 보내지 말고 파일로 저장. 390/1440px 반응형. 주석 금지.
검증: 필수 파일 존재, node --check app.js, 브라우저 콘솔오류 없음, 검색/생성/검증/저장/복제/보관/복원/재로딩 실제동작, 가로 넘침 없음. 미실행 시각 검증을 통과했다고 하지 않는다.
